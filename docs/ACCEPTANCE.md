# 用户验收清单

本文件规定验收方法，不表示所有项目已经通过。已完成范围与未完成项见 [发布说明](../RELEASE-NOTES.md) 和 [审查记录](../reviews/CLAUDE.md)。安装版本以 [安装说明](../INSTALL.md) 为准。

## 安装与配置保留

在独立 DSH_HOME 或另一台电脑安装五个同版本插件。分别验证首次安装、旧版升级和 tgz 转 npm。核对版本、启用状态、API Key、数据源、默认模式及历史会话保留。凭据只在本机配置，不放入截图或日志交付包。

## 真实用户流程

通过 DSH 页面上传或从已配置数据库查询数据，用简短业务问题发起任务。先验证用户路径，失败后再查源码；独立 API 调用不能代替界面验收。

| 场景 | 验收重点 |
| --- | --- |
| 钢材回归 | 上传、预测、真值指标、结果下载；独立重算误差 |
| 玻璃形成分类 | 类别结果、混淆矩阵、分类指标；预测行与输入对应 |
| 日需求时序 | 未来时间范围、预测曲线、分位数；基线仅使用历史数据 |
| 单行、10 行、全部样本解释 | 范围正确、原始行号保留、贡献矩阵与下载一致 |
| 解释可视化 | 热力图/逐样本切换、筛选/总体对照、带符号均值、图例、长名称、全屏与导出 |
| 光学关系探索 | 有向/无向状态、孤立变量、循环、聚焦与完整网络；失败不绘制成功结果 |
| 模型比较 | 相同拆分、指定模型、指标方向、部分失败与续查；CSV/JSON/HTML 可打开 |
| 业务报告 | Markdown 和离线 HTML；数字、图片、样本范围和结论一致；历史版本可下载 |

## 边界与回归

- 无真值时不显示评估误差；抽样解释不冒充全量结论。
- 输出路径与输入冲突时拒绝写入，输入摘要保持不变。
- 检查取消、网络错误、部分完成与重启后的历史记录。
- 检查运行文案、任务摘要折叠和到对应轮次“任务流程”的跳转。
- 新建标准模式会话，确认无 LimiX 专属工具、提示词和首屏引导。
- 数据源覆盖连接成功与失败、保存后重启、只读查询及 CSV 导出。

## 证据与判定

每项记录版本、平台、操作、预期、实际和截图。失败回执与任务 ID 留在本地排障包，不放到公开发布说明。录屏不完整时标注“关键交互截图”。

任务成功、界面通过、下载一致、报告事实核验分别判定。真实服务、浏览器全流程、桌面端、第二台电脑和 Windows 分别记录；未验证项目不得由其他环境的结果替代。

已知光学 20 变量无向解释上游错误继续保留；3 变量成功且无边不能证明完整案例已修复。报告仍需人工审阅。
