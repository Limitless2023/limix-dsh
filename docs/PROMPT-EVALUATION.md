# 提示词跨场景验收

## 执行方法

候选版本必须通过未参与逐句调优的场景；同题多次试改不能作为泛化通过。运行使用真实模型，保存提示词版本、原问句、工具调用与完整回答。退出码为0仅表示模型完成回答，不代表答案正确。

2026-11-02 测试使用 DSH 0.2.1-rc.5 headless。逐字提取 prefix/suffix，并加载源码注册的预测、解释、比较和报告四段指引。headless 没有桌面 preset 的完整工具和界面，这属于提示词行为测试；不能替代生产预测或完整标准模式回归。测试原件保存在维护者仓库外。

## 固定案例与判定

| 案例 | 输入概要 | 必须满足 |
| --- | --- | --- |
| 材料 | 300条成分与抗拉强度，无热处理记录，想减少试验 | 区分预测与候选筛选；询问工艺是否一致；不推断新配方必然外推，不把强度离散直接归因于工艺 |
| 设备 | 半年振动/温度，2次故障，想提前7天预警 | 按独立故障事件评估证据；不臆造采样频率；不把同故障的多个测点当独立故障扩样 |
| 促销 | 每日销量、价格、促销标志，想算增量 | 解释分数不是干预收益；询问分配机制，不断言客户非随机促销、降价或单店；效应方法须说明识别条件 |
| 明确任务 | 指定CSV，仅检查列名、行数、缺失，不预测或生成文件 | 读取指定文件并准确回答，不重新访谈或调用预测；样例为3行、mn列第三行缺失 |
| 文献 | 没有客户数据，检索两篇食品光谱测水分原始论文 | 实际搜索并读取，给链接/年份/数据条件与验证方法；不将论文指标承诺为客户效果 |

## 本轮发现

重组后明确的CSV检查任务通过。材料、设备、促销三个场景仍有无依据断言或错误方法建议，质量门槛未通过；没有将正确的方向判断当成整题通过。初次探索仍偏长，两个问题常夹带多个子问题。

本轮停止对单题继续追加补丁。发布前应独立复核文献方法与引文，补充完整桌面执行及跨模型回归；未通过前不将候选版本视为可发布。

文献案例实际检索并读取了两篇原始论文，链接与方法比较已输出；仍有未经证明的不可复现判断、检索次数偏多，标为部分通过，论文数值尚未独立逐项核验。

## 自动检查与边界

报告工作流迁移后的工具测试验证四段指引仅注册一次、三类命令不变、标准模式安装隔离、图表渲染和文件保护。运行时隔离测试与模型行为评分分别记录。

提示词结构改善不保证推断正确。需要保留人工审阅，尤其是可行性、因果识别与行业机理结论。

## 文理双脑候选：对照与消融

继续使用同一 DSH、deepseek-flash / Max 和相同问题，比对上一版与缩短后的核心提示词。两组均加载四段技术指引。新增物流赔付、办公楼节能和免检场景。每组每题仅一次，属于问题发现，不是稳定性统计。

精简版未稳定改善：材料回答由789字符增加到1280字符，促销从707增至841；促销回答还错误描述了解释接口的干预能力。物流预设承诺策略可改变；节能在没有检查数据前断言某些效果无法验证；免检给出未经依据的抽样比例。均保留为未通过项。

固定标记探针返回指定标记，配置转储也确认 persona 注入生效。仅保留核心提示词的消融测试仍出现过度展开；促销咨询还扫描了未指定的数据目录。不能据此将失败归因于技术指引的长度，也不能声称拆分文件即解决问题。

在 suffix 增加短咨询示例与200—400字目标；三类技术指引明确咨询不触发执行或运行环境检查。复测材料、促销、CSV检查、物流，并加入餐厅浪费这一新问题。沿用四段完整技术指引，每题一次。

| --- | --- | --- |

| 促销 | 646字符，无工具调用；接口能力表述纠正，但仍过早选定对照方案，暗示统一投放即外生变化 | 部分通过 |
