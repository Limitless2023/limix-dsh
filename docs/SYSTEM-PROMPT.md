# LimiX Agent 提示词设计

## 唯一来源

不在文档中维护第二份完整提示词。实际内容以以下源码为准：

- [preset 配置](../packages/preset/cordis.patch.yml)：角色、公共约束和输出要求。
- [预测指引](../packages/tool/src/host/predict-command.js)：预测任务与输入附件。
- [解释指引](../packages/tool/src/host/explain-command.js)：局部贡献、样本范围和关系探索。
- [比较指引](../packages/tool/src/host/benchmark-command.js)：固定拆分、指定模型与基线。

这些指引只在 LimiX preset 加载。完整运行上下文还包含 Harness 通用规则、工具定义和会话信息。标准模式不加载这些专属指引。

## 行为约定

预测前核对目标、数据字段、时间范围和特征在预测时是否可用。有真值才报告误差；任务完成不等于模型效果可用。

解释明确单行、抽样或全量范围。贡献热力图和带符号均值使用一致的样本范围；未知方向不补零。模型归因、关系探索与干预效果分别表述。

比较使用同一训练与测试拆分，遵守指定模型范围。当前专用比较入口支持分类与回归；不将时序任务伪装成表格回归。失败不补零，超时先查已有回执。

综合任务默认生成 Markdown 和带图 HTML，简单追问保持短答。先通过 `report --inspect` 读取程序事实，再组织业务正文。缺少背景、库存或配方时不编造；历史报告另存，输入文件不得覆盖。

提示词是行为约束。报告中的业务推断仍需人工审阅，不能将自动检查通过表述为所有结论正确。
