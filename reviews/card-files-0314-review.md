# 0.3.14 卡片与任务文件审查

## 范围

审查 Agent 的折叠状态、任务文件提取、菜单定位、热力图样式隔离，以及与宿主文件预览的衔接。其余四包仅同步版本。未改变 API、提示词或数据源存储。

## 结论

未发现阻断发布的问题。文件输出以成功保存回执为准，不把输出参数当作已生成文件；远程 URL 和版本 ID 不当作本地路径。相同路径合并用途，打开权限交由宿主。

折叠隐藏展示而不卸载图表；全屏前展开，打开侧栏文件时退出模态全屏。菜单保持原 DOM 委托，支持外部点击与 Esc 关闭。固定矩阵高度限定于关系矩阵，贡献热力图按画布比例定高。

## 验证

- 五包构建、Node/Python 自动测试、打包契约与独立解包载入全部通过；Agent 90 项测试通过。
- 真实 DSH 会话中，第 9 行选择在收起/展开后保留，收起状态仍能进入全屏。
- 真实回归 249 行训练、5 行预测返回 finished，结果文件在侧栏显示 5 行；本次未提供真值，不作模型效果结论。
- 旧钢材与光学解释均能打开调用中引用的输入文件。
- 普通卡片热力图 SVG 从 400px 减为约 272px，去除画布上下白边；全屏底部操作可见，关系矩阵保留自身 400px 规则。
- 悬浮读数、点击色块浮层正常，点击不自动跳转单条解释。

## 保留边界

刷新后折叠状态恢复默认；没有持久化用户卡片偏好。文件移动或删除由宿主显示打开失败。仅有远程版本 ID 时没有本地输入文件入口。分类与时序文件提取由自动测试覆盖，本轮文件入口实测为回归与解释。报告仍需人工审阅；既有提示词未通过项和 20 变量无向解释上游报错保留。
