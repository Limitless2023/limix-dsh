# 0.3.13 因果解释 UI 审查

审查日期：2026-11-03。范围：关系网络、场景关系对比、批量贡献与单条解释，以及结果文件和图片导出。

## 审查发现及修复

1. 场景比较原先仅校验目标与变量，没有校验实际模型。现保留服务返回的模型标识和处理口径；缺少标识或两组不一致时拒绝比较。
2. 单条解释导出原先复用全量贡献矩阵。现仅导出当前样本，使用与界面相同的正负贡献方向；高低组导出明确两个组名。
3. 场景比较写入多个文件时，后续失败会遗留前面文件。现只清理本次创建的文件，拒绝覆盖已有路径。
4. 真实 DSH 中场景比较回执被截断，JSON 无法解析，卡片未渲染。现回执只传本地详情路径与 SHA256；读取时先核验文件，再显示完整图表。结果和 CSV 保留完整精度。

运行 `node scripts/validate.mjs --output <本地验收目录>`：五包构建、Node/Python 回归测试、取消测试、打包清单、仓库外解包载入与 CLI 帮助检查通过。

新增验证覆盖：模型/处理口径不一致、部分写入失败清理、单样本导出、双组命名、两组详情身份、精简回执摘要和文件内容篡改拒绝。
