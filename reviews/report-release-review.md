# 0.3.1 报告、界面与五插件发布审查

日期：2026-11-01。环境：macOS，DSH 0.2.1-rc.2。
独立审查者：review_prompt_release、review_ui_release。

## 审查范围

- 提示词：预测、局部解释、关系探索、模型比较、报告交付及标准模式隔离。
- 界面：辅助工具紧凑卡、贡献热力图长标签、键盘访问及字段映射。
- 发布：五包版本、入口、Python 模块、源码一致性及附件校验。
- 文案：逐项核对版本、证据、已知边界和链接；本机未发现 copy-check 技能，采用独立交叉复核。

## 发现与修复

1. 初次界面实测遗漏用户指定的预测模型，随后默认解释模型也与预测不一致。预测流程现要求显式传入指定模型，并核对实际返回；解释流程沿用原预测模型，拒绝后不擅自切换。
2. 早期报告将预测范围、少量成分或粗分组数量当作物理合理性、外推或误差原因的证据。输出规则已禁止这些推断，默认报告只分析核对过的输入与工具结果。
3. 无真值报告的限制原先覆盖过宽。已限定为仅预测场景；已完成的解释仍可报告，但不能据此证明预测精度。
4. 时序解释指引曾把训练文件要求写成通用条件。已明确时序沿用结果版本；表格解释才补齐缺少的训练数据和目标。
5. 说明文档曾保留旧版本号和维护者本机链接。版本已统一；本地证据明确标注为未随仓库发布。
6. 报告复测暴露错误建议：MAE 不能换算误判率，`--truth` 不是已有 CSV 的独立评分入口。流程现明确这两项边界，并区分训练均值基线与 R² 的测试真值均值参照。
7. 报告曾追加未核验的贡献尺度换算与平均绝对贡献。默认报告改为一页左右，仅概述真实返回；批量局部解释沿用带正负平均贡献，关系探索使用节点、边和关系分数。

## 实机与真实 API 验证

输入为公开 steel_strength 数据的固定演示拆分：参考 249 行、测试 5 行、13 个成分特征。不是最终选型基准。

- LIMIX_16M 预测、5/5 行局部解释、LIMIX_16M 与 BASELINE 比较均完成。
- 比较返回 MAE 71.4012 MPa、RMSE 95.9253 MPa、R² 0.8881；基线对应 321.9743 MPa、431.1327 MPa、−1.2610。
- 基线使用参考集目标均值 1636.3257 MPa，对所有测试行输出同一值。
- 局部解释返回 65 条贡献记录，缺失样本为空。
- 单独 LIMIX_7M 无真值预测完成 5 行，未返回误差指标。
- 标准模式实测没有 limix 工具；专属首屏推荐未出现。

本轮另发现 LIMIX_7M 局部解释在创建阶段返回 4103，未生成 task_id。同源 LIMIX_16M 成功。官方接口文档列出 7M，原因待后端核对，不能据此断言所有 7M 解释均不支持。

维护者本机证据：`../_recon/report-validation-v0.3.1/`，不随仓库发布。首轮不合格报告保留用于诊断，不作为交付样例。

## 验证边界

本轮未重跑分类、时序和光学关系 API。20 变量光学无向解释仍是已知上游错误。中文进度、报告格式与分析克制均属于模型行为约束，不是输出强校验。

## 最终报告复核

新会话未显式要求报告格式，Agent 自动输出业务分析并保存 Markdown。综合报告包含业务、249/5/13 数据规模、两模型指标、5/5 行解释、主要带正负贡献及下一步。无真值报告标明背景未提供、无法评估误差，且模型归属仅据用户说明。

独立复核发现综合初稿仍把额外平均排名误写成“单行排名”。原会话已按复核意见删除该句，未重跑 API。修订稿的指标、贡献、模型和 8 个链接复核通过；无真值稿的数值与 4 个链接通过。

报告预览和全屏已在桌面打开。5 份受保护输入的 SHA-256 未改变。两份最终报告位于本机证据目录的 `accepted/` 和 `accepted-no-truth/`。
简单追问实测只给短答，没有调用工具或新增报告。

本次验收不宣称提示词能杜绝模型错误。分位统计和篇幅仍有软约束偏离；对外使用报告前应核对事实与统计口径。

## 分发核验

候选五包均为 0.3.1，99 个普通文件与对应源码一致。入口、patch、locale 与 7 个 Python 模块完整；未包含环境配置、node_modules、缓存、绝对路径成员或链接成员。SHA-256、manifest 的字节数和 SHA-512 integrity 核验通过。

最终发布包必须从提交后的干净工作区重建，并再次核对源码提交和附件摘要。Release 附件为五个 tgz、manifest.json 与 SHA256SUMS。
