# v0.3.7 Scenarios 交叉审查

审查日期：2026-11-01。范围：v0.3.6 后的报告、依赖环境、解释预检与抽样、时序基线、热力图及五包分发变更。

三路独立审查覆盖后端、报告与界面、预设与分发。修复后交换检查后端与报告代码，主 agent 运行最终构建和测试。没有把自动检查等同于全部用户验收。

## 发现与修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| P1 报告猜测首个 `pred_` 列 | 多目标导出会评估错误预测列，可能显示虚假的高精度 | 仅接受 `pred_label` 或精确的 `pred_<target>`；缺列拒绝生成 |
| P2 时序历史顺序与边界未校验 | 未来或乱序历史被连到预测前面 | 拒绝无效日期、非递增日期和不早于预测起点的历史 |
| P2 自定义 CLI 改变安装器目录 | 外部 CLI 旁没有安装器时，模型比较不能自动准备依赖 | 安装器路径固定使用插件包内资源 |
| P2 创建环境取消不完整 | venv/ensurepip 后代可能残留 | 通过共用进程树终止机制创建环境 |
| P2 解包目录复用 | 缺少入口的新包会借用旧文件通过检查 | 每包创建全新隔离目录；release/validate 共用文件契约 |
| P2 普通文件登记驱逐旧报告 | 仍存在的历史报告被误报丢失 | 报告读取记录与普通结果的数量保留策略分开 |

最终检查通过 198 项测试：Node 106 项、工具 Python 63 项、基准 Python 29 项。五个插件构建、包文件契约、全新目录隔离加载均通过；工具包 Python 入口通过独立启动检查。另用最终构建检查五份真实场景报告清单，均通过 `report --inspect`，未重新调用上游 API。

三路复查未发现尚未修复的确定性发布阻塞项。本次审查修复通过自动测试与真实文件检查验证，未重新跑完整界面流程。原生界面证据来自修复前的本轮场景验收。

取消测试期间，macOS 曾出现一次进程退出后 `killpg(SIGKILL)` 返回 `PermissionError`；后续复跑和最终取消测试通过，未稳定复现。此异常保持显式失败，不会把环境误标为就绪。跨平台取消仍需实机观察。
